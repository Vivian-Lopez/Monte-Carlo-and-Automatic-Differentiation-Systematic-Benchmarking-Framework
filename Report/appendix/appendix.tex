\section{Report Artefact Generation}

The figures and tables in Chapter~\ref{chap:evaluation} are generated from the stored result files with:
\begin{verbatim}
python3 Final_Year_Project_Report/evaluation/generate_report_assets.py
\end{verbatim}

The script reads the framework database at \code{results/benchmarks.db} and writes LaTeX tables under \code{Final_Year_Project_Report/evaluation/tables/} and PNG figures under \code{Final_Year_Project_Report/evaluation/figures/}.
